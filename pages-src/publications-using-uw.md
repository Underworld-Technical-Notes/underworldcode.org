These papers used Underworld to produce their results. It is worth looking at
the [underworld-community](https://github.com/underworld-community) organisation
too — simplified versions of the scripts behind some of this work have been
shared there.

The list is maintained as a public
[Zotero library](https://www.zotero.org/groups/2386948/underworld/library) and
baked into this page when the site is built, so the two cannot drift.

**Missing, or wrong?** [Open an issue](https://github.com/Underworld-Technical-Notes/underworldcode.org/issues/new?title=Publication%20to%20add)
with the DOI, or email `help@underworldcode.org`. Either reaches us; the issue
is better, because then you can see it has been picked up.

If you are about to publish, the [citation page](/how-to-cite-underworld/) has
the references for the code and for the algorithms behind it.
