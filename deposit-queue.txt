# Notes approved for deposit, one slug per line.
#
# This file is how a DOI gets minted. A note reaching `main` without a record
# causes a pull request to be opened that adds it here; MERGING that pull
# request is the decision, and the push runs the deposit workflow.
#
# So: the reminder is automatic and the act is not. Nothing is deposited
# because a note was published -- only because somebody merged the request to
# deposit it.
#
# Entries stay after the deposit. They are a record of what was approved and
# when, and the workflow skips anything that already has a record, so a stale
# line is inert.
